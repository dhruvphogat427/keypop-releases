# KeyPop downloads

KeyPop plays a sound on every key you press: mechanical clicks, piano notes, arcade combos and more. For Windows 10 and 11.

- **Website and demo:** https://keypop.fun
- **Latest version:** [Download KeyPop.exe](https://github.com/dhruvphogat427/keypop-releases/releases/latest/download/KeyPop.exe)

This repository only hosts the app's download files. Open KeyPop.exe to run it; there is nothing to install.

If Windows shows a "Windows protected your PC" box, choose **More info**, then **Run anyway**.
